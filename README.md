# Go-Global-GT_IMZ-Exhibit
Interactive installation raising awareness of Georgia Tech's study abroad program.

This project showcases the interactive installation designed for the IMZ (Interactive Media Zone) at the Georgia Tech Library. The exhibit aims to raise awareness about GT's study abroad programs through immersive storytelling, collage art, and motion design.

---

## 🖥️ Project Structure

- `GGgexhibit.json` — core data file used to link locations, images, and quotes
- `wall_content/` — background video loop for the IMZ LED screen
- `touch_content/` — content shown on interactive touchscreens
- `JSON_Content/` — text and media assets referenced in the JSON interaction file

---

## 💡 Technologies & Tools

- Large-format LED video loop (IMZ)
- Touchscreen interaction with visual storyboards
- JSON-based interaction logic
- Adobe Creative Suite, Figma, Premiere Pro
